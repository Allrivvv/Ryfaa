# Praktik Python Dasar

Repository ini berisi hasil praktik pembelajaran Python dasar dari Bab 01 sampai Bab 11.

## Daftar Materi

1. Pengenalan Python
2. Variabel dan Tipe Data
3. Input dan Output
4. Operator
5. Percabangan
6. Perulangan
7. List, Tuple, Set, dan Dictionary
8. Function
9. Error Handling
10. Module dan Package
11. Pengolahan Data Sederhana

## Tools

- Python 3
- Visual Studio Code
- Library pandas untuk praktik pengolahan data

## Tujuan

Repository ini dibuat untuk mendokumentasikan latihan kode
Python dasar dan memahami penerapan setiap materi melalui praktik.
